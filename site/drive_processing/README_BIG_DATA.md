# Big Data

La carpeta [Big Data en Drive](https://drive.google.com/drive/folders/1thGWH7iyzwmC3YDjMHf1J_vwmPfNpm8H) alimenta los gráficos diarios de consumo y datos territoriales con `Datos_informe.csv`. El mapa de calor prioriza las cifras mensuales y semanales de `Tabla_monitor.csv` y conserva el histórico fuera de los periodos que cubre el CSV.

La hoja «Alta Frecuencia - España» alimenta el gráfico de prueba de **Datos manuales**. Las series históricas de inversión, actividad sectorial y consumo nominal de Big Data siguen disponibles en la copia ya generada.

Las rutas de las tres carpetas, sus destinos y la instalación de Apps Script están descritas en [Sincronización de Drive](apps_script/README.md).
